# 玩家手册 · 航空公司模拟经营 Ver 1.0

你是一家航空公司的老板。开局有 **3,000 ¥M 现金**、**1 架 A320**、以 **北京（PEK）** 为基地，
对面是 **50 家 AI 航司**，它们会自己开线、调价、买飞机、也会破产。

目标只有一个：**比它们活得久、赚得多**。沙盒里没有终点；目标模式里你有 10 个游戏年。

---

## 1. 启动与退出

### 启动

双击 **`start.cmd`**。脚本会：

1. 找一个 Python 3.9+（找不到会提示，并告诉你怎么办）
2. 在独立窗口启动后端
3. 等后端就绪后自动打开 <http://127.0.0.1:8777/>

如果页面没自动打开，手动访问 <http://127.0.0.1:8777/> 即可。

### 退出

三种方式，效果都一样（都会先自动存档）：

| 方式 | 说明 |
|---|---|
| 双击 **`quit.cmd`** | 推荐。存档 → 停后端 → 自动收尾 |
| 页面右上角「存档 → 保存并退出」 | 后端自己停，浏览器可以留在原地 |
| 直接关掉后端那个黑色窗口 | 也能停，但最多回退到最近一次自动存档 |

> **只关浏览器标签不算退出**：游戏时钟跑在后端，回来刷新页面就能接上。

### 重开一局

```bat
start.cmd -NoResume
```

`-NoResume` 表示不读自动存档，从第 0 天重新开始。原来的存档不会被删，仍可在「存档」面板里载入。

## 2. 第一次开局：选模式

新对局会先弹「开局模式」面板：

| 模式 | 规则 | 建议 |
|---|---|---|
| **沙盒** | 无终点，不追踪目标，随时存档退出 | 第一次玩选这个 |
| **目标** | 从第 0 天起追踪 4 个目标，期限 **3600 游戏日 = 10 年** | 熟悉之后再挑战 |

目标模式里：

- 4 个目标全部达成就**提前结算**，否则到 3600 天**到期结算**
- 达成个数 **4/3/2/1/0 → A/B/C/D/E**；0 个是「未达成」，**不计分**
- **破产 = 目标失败**，不计分
- 结算后自动暂停，只能重新开局或换模式

四个目标的判定口径（面板里也会写）：

| 目标 | 达成条件 |
|---|---|
| **市值进前三** | 10 年内，任意一天公司市值排名 ≤ 3 |
| **区域霸主** | 任意一天，你在某个区域的客流份额 ≥ 35% |
| **高质高效** | 连续 **24 个月**：EBITDA 率 ≥ 15% 且客流加权准点率 ≥ 85% |
| **网络扩张** | 某一天同时满足：航段数 ≥ 100 且客流加权平均载客率 ≥ 75% |

> 区域份额是按航线客流在「航段两端所在区域」均摊的近似值，不是审计口径。

### 右上角按钮

| 按钮 | 用途 |
|---|---|
| **教程 / 指令** | 快速上手说明 + 11 条高级指令的语法，可一键「填入」 |
| **数据看板** | 全部航线的客座率/利润率/航距排序，点行直接跳到该航线 |
| **目标 / 模式** | 看四个目标进度、剩余天数；沙盒/目标之间切换 |
| **存档** | 命名保存、载入、删除；保存并退出 / 保存并重启 |

### 地图

- **开线手势**：右键=起点，左键=终点，Alt+左键=经停点（详见 §4）
- **选中起点后地图会自动聚焦**：只保留经过这个机场的航线（你的蓝色/黄色、AI 的灰色），其余压暗，
  一眼看出这个机场已经连通了哪里、还有哪些方向没被占
- 滚轮缩放，拖拽平移；顶部可切「全球 / 我的网络」
- 缩放级别低时自动只显示大机场，放大后小机场才出现
- 同城机场（上海 SHA/PVG、东京 HND/NRT、首尔 ICN/GMP、曼谷 BKK/DMK）低缩放时合并显示，点开可左右拆分
- 左上「AI 航线」开关：AI 的航线是灰色；和你的城市重叠时双方转暗黄（＝竞争）。悬停可看班次/机型/客座率/价格指数
- 点 AI 航线打开「航线详情」：可看它的价格指数与各 OD 的经济/商务票价（成本与财务不公开）
- 你的航线是蓝色，竞争航线是黄色；点地图上的航线直接打开调价/班次/关线面板

### 侧栏

- **KPI**：现金、负债、日客流、日 EBITDA、口碑、机队/航线数、当前排名
- **我的航线**：每条航线的载客率进度条，点行进入管理
- **竞争对手**：市值前 20 的对手，带名次；标签显示 `TOP 20/49` 表示「显示 20 家、共 49 家」
  你自己不在这个榜里（你的名次显示在 KPI 区）

## 4. 怎么开始赚钱

### 第一步：开一条航线

最快的方式是**在地图上点机场**，三个手势分工不同：

| 手势 | 作用 | 标记 |
|---|---|---|
| **右键点机场** | 选航线起点 | 黄色 `① 北京` |
| **左键点机场** | 选终点，立刻弹出开线向导 | 黄色 `② 上海` |
| **Alt + 左键点机场** | 加/取消经停点（再按一次取消） | 紫色 `经 成都` |

1. **右键**点起点（比如北京）—— 顶端会提示「已设为起点」
2. **左键**点终点（比如上海）—— 弹出开线向导，显示这一市场的情报：

   ```
   航距 1091 km · 总出行需求 22,858/日 · 航空需求 10,589/日
   现有运力 493 座（运力/需求 4.7%）· 参考票价 经济 ¥994 / 商务 ¥2,585
   竞争者：AI-01、AI-06、AI-09  建议班次：14
   ```

3. 看「**运力/需求**」：低于 10% 说明市场还很空，值得进；高于 40% 说明已经很挤
4. 设定班次和机型，点「开通」

**要开经停航线**：右键起点 → Alt+左键点经停机场（变紫）→ 左键点终点。向导会显示
`PEK → CTU → LXA`，并列出每一段航距、总航程与绕行系数；经停航线没有直飞市场数据，
开通时由后端逐段校验航程、绕行与时刻。

也可以用底部「**开航线**」按钮，用选择框选 起点/终点/经停/班次/机型。

### 第二步：盯三个数字

| 数字 | 在哪看 | 怎么读 |
|---|---|---|
| **载客率（LF）** | 侧栏进度条、数据看板 | > 95% 且经常售罄 → 该加班次或提价；< 60% → 降价或减班 |
| **利润率（margin）** | 数据看板 | 航线级「可归集口径」，不含折旧、总部固定费与利息 |
| **日 EBITDA** | 侧栏 KPI | 长期为负就要动手术 |

### 第三步：扩大规模

| 动作 | 入口 | 要注意 |
|---|---|---|
| 调价 | 航线管理 → 价格指数滑杆 | 允许 0.50–1.50 倍参考价 |
| 改班次 | 航线管理 → 班次数字框 | 1–14 班/日，受机队运力限制 |
| 买/租飞机 | 机队 → 选机型/基地/是否租赁 | 租赁省现金但每天付租金；买断吃现金 |
| 设新枢纽 | 设枢纽 → 选机场 | 三档门槛（客流/航线/现金）+ 开设费，面板会实时显示 |
| 贷款 | 贷款 → 输入金额 | 有授信上限；负债超过 3 × 权益会破产 |
| 改名 | 点侧栏公司名，或「改名」 | 2–20 字，不能和别家重名 |

**调价前先看「竞争者」**：航线管理面板里选一条航线，中间那块卡片会列出同一市场里所有
AI 航线的**班次、载客率、价格指数**，并在同一个 OD 上把**你的经济舱票价和对手并排**列出，
标明对手比你低/高多少。判断口径：

- 对手 LF 也很高（> 85%）→ 市场吃不饱，可以跟着提价
- 对手指数比你低 10% 以上、LF 还比你高 → 你的价格没竞争力，要么降价要么减班
- 对手指数比你高、LF 却比你低 → 你还有提价空间

对手的成本与财务是看不到的，能比的只有这三项公开数据。

### 破产线（两条，任一触发就清算）

1. 现金 < 0，且已经借不到新钱
2. 负债 > 3 × 权益

## 5. 时间与节奏

- 默认 **1 游戏日 = 60 秒**；启动时默认 **4 倍速**，所以约 15 秒一天
- 顶栏可暂停 / 1× / 4× / 16×
- **自动存档每 60 秒**一次，写在 `saves/autosave.json`
- 关页面时会再补一次自动存档

想玩快点（开发/试玩用）：

```bat
start.cmd -Speed 16
```

## 7. 常见问题

**双击 start.cmd 黑框一闪就没反应？**
在这个文件夹里打开 PowerShell，执行 `.\start.ps1 -NoBrowser`，报错会停在屏幕上。

**提示「没有找到 Python 3.9+」？**
去 <https://www.python.org/downloads/> 装，安装时勾选 **Add python.exe to PATH**，重开一个命令行窗口再试。

**提示「检测到端口 8777 上已有游戏在运行」？**
这是正常的：上次的后端还活着，脚本只帮你开浏览器。想重开就先 `quit.cmd`。

**页面打不开 / 一直白屏？**
1. 看后端黑窗口有没有报错
2. 检查端口：`netstat -ano | findstr :8777`
3. 浏览器按 `Ctrl+F5` 强制刷新（前端是静态文件，更新过后一定要强刷）

**「AI 航线」开关提示没有 AI 航线？**
第 0 天 AI 还没开线，推进 1–2 天就有了，不是故障。

**中文显示成方块/乱码？**
用 Windows 10/11 自带的 PowerShell 窗口运行；或在窗口里先执行 `chcp 65001`。

**我关了浏览器，游戏还在跑？**
对的。时钟在后端，不关浏览器不影响。要停就 `quit.cmd`。

**存档在哪？换电脑怎么办？**
`saves/` 目录里的 `*.json`。整个文件夹拷走即可，存档是纯 JSON，可读可备份。

**想要桌面图标？**
右键 `start.cmd` → 「发送到」→「桌面快捷方式」；对 `quit.cmd` 同样操作一次就有两个图标。
快捷方式指向的是这个文件夹，**别单独移动 .lnk 而不移动文件夹**。

**一个对局多大？**
自动存档约 0.4 MB，随天数与 AI 数量增长，远小于 5 MB 上限。

## 8. 一点点经验

- **先窄后宽**：早期用 A320 专注 2–4 条高需求短途（京沪、京广、沪广），把载客率养到 85% 以上再复制
- **看运力/需求比再进市场**：向导里这个数字 < 10% 是好生意，> 40% 是价格战
- **载客率长期 98% 不一定是好事**：说明你在白送钱，加价或加班次
- **别急着设第二个枢纽**：门槛和开设费会吃掉早期现金
- **贷款是杠杆不是收入**：负债到 3 × 权益就清算，扩张期留至少 3 个月成本的现金
- **机龄会说话**：每架飞机每天机龄 +1/360，准点率与口碑会慢慢掉，旧机该卖就卖

祝你好运，别让 AI-07 抢了你的京沪线。
