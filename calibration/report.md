# 航空公司模拟经营 · 系数校准报告（v1.1 能级制）

> 自动生成，请勿手改。数据源：`airports.csv`（63 机场 / 59 城市）、`anchors.csv`（20 基准城市对）、`fares.csv`（9 条票价样本）。

## 1. 模型变更说明

本版按需求评审结论，把 v1.0 的**重力模型**换成了**能级制需求模型**：

| 项 | v1.0 重力模型 | v1.1 能级制（本版） |
|---|---|---|
| 需求驱动 | `(Ta·Tb)^alpha · f(d)` | `w(能级A) · w(能级B)` |
| 距离的角色 | **降低需求** | **不降低需求**，只提高口碑敏感度 |
| 参数识别 | `alpha/beta/dmax` 三者共线，不可识别 | 能级权重与区域系数线性可解 |
| 枢纽效应 | 吞吐量直接进入需求，枢纽被高估 | 吞吐只用于定能级；枢纽靠连通度 `conn` 加成 |

这样处理同时解决了三个问题：参数可识别、枢纽不再被系统性高估、距离的经济含义从「需求」转移到「服务质量压力」。

## 2. 机场能级划分

按年吞吐量划档，城市能级取其全部机场吞吐量之和所对应的档位：

| 能级 | 名称 | 吞吐量阈值 | 城市数 | 权重 w |
|---|---|---|---|---|
| XL | 超大机场 | ≥ 80 百万人次 | 8 | 1.0000 |
| L | 大型机场 | ≥ 45 百万人次 | 22 | 0.4624 |
| M | 中型机场 | ≥ 25 百万人次 | 14 | 0.2138 |
| S | 小型机场 | ≥ 10 百万人次 | 12 | 0.0989 |
| R | 支线机场 | < 8 百万人次 | 3 | 0.0457 |

权重以 XL = 1.0 归一。`w` 的比值才是实际使用的量，例如两个大型机场之间的需求是同等级超大机场的 0.214 倍。

## 3. 需求公式

```
D_total(A,B) = C · w(scale_A) · w(scale_B) · C_region · conn_A · conn_B
               C = 21454.8918
D_air(A,B)   = D_total(A,B) · sigmoid(c0(d))
```

`D_total` 是**总出行需求**（含高铁、自驾），`D_air` 才是航空客流。游戏里只需要实现 `D_total` 与 logit，方式分担由 logit 的外部选项 `U_0 = 0` 自动完成。

整体拟合优度（对数域 R²）= **0.8689**，平均绝对误差 **23.7%**

## 6. 距离 → 口碑敏感度（D2）

```
c_rep(d) = min(1.20, 0.25 + 0.000075 · d)
```

| 航距 km | c_rep | 相对短途的倍数 | 设计含义 |
|---|---|---|---|
| 300 | 0.273 | 1.0× | 短途：口碑几乎不影响选择 |
| 1,000 | 0.325 | 1.2× | 短途：口碑几乎不影响选择 |
| 2,000 | 0.400 | 1.5× | 中途：开始明显 |
| 4,000 | 0.550 | 2.0× | 中途：开始明显 |
| 6,000 | 0.700 | 2.6× | 远程：口碑决定成败 |
| 8,000 | 0.850 | 3.1× | 远程：口碑决定成败 |
| 10,400 | 1.030 | 3.8× | 远程：口碑决定成败 |

**这就是「自动引导使用更舒适机型」的机制**：长航线上 `c_rep(d)` 被放大，而口碑里的 `comfort_score` 由机型舒适度驱动，因此用舒适度低的机型执飞长航线会损失大量份额——不需要额外写「机型航程限制」，市场上自然会淘汰不合适的机型。

## 7. 枢纽连通度（D3）

```
conn(i) = min(1.80, 1 + 0.50 · ln(1 + routes_i / 100))
```

| 该机场在营航段数 | conn 乘子 |
|---|---|
| 0 | 1.000 |
| 50 | 1.203 |
| 100 | 1.347 |
| 200 | 1.549 |
| 400 | 1.800 |
| 800 | 1.800 |
| 1600 | 1.800 |

这是**唯一一个随游戏进程动态变化的需求项**：首尔、迪拜这类中转城市在开局时按能级获得基础 OD，随着各公司在当地铺设航段，其客流吸引力逐步上升。乘子同时作用于两端城市，因此「把别人的枢纽做大」也会抬高你自己的 OD 池——这让枢纽战争变成正和与零和交织的博弈。

## 12. 遗留风险

```
1. 能级制把同档城市视为等价：广州与成都、深圳与杭州在模型中没有区别
   → 缓解：后续可为每档内再加一个 ±15% 的城市系数，由锚点残差反推
2. 需求不随距离衰减，短途干线的利润率会显著高于长航线
   → 需要靠「时刻稀缺 + 机队周转上限 8 段/日」限制短途航班数量，
      若实测短途收益仍压倒性占优，再考虑加一个极弱的距离项（beta ≈ 0.15）
3. conn 乘子会让大枢纽在后期滚雪球
   → 已设 cap 1.8；若仍失控，改为按「排名分位」而非绝对航线数计算
```
